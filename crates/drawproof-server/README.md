# drawproof-server

Minimal receipt signer for one independent party.

## Install

```sh
cargo install --path . --locked
```

## Sign a commitment

```sh
drawproof-server sign --key signer.key --commitment commitment.json --out receipt.json
```

The signer:

1. Loads the key and rejects group- or world-accessible modes on Unix.
2. Parses and validates the commitment.
3. Fetches and verifies the latest drand quicknet beacon.
4. Refuses when the selection round is published, including a direct check that
   the round is not yet fetchable.
5. Signs the canonical receipt message with its Ed25519 key and writes the
   receipt.

The `signed_at_round` field records the verified round at signing time. A
verifier only counts receipts with `signed_at_round` below the selection round.
The signer also fetches the selection round directly and refuses if it already
exists. With the default endpoint, the latest round must be within four rounds
of the local clock. A relay can withhold data, but it cannot forge the BLS
proof; a custom mirror is the operator's trust choice.

## Keys

```sh
drawproof keygen --name signer-a --out signer-a.key
```

Keys are generated by the client binary, written with mode 0600, and never
overwritten. Publishing the public key is safe; the secret key must stay
private. The server supports one key per invocation.
